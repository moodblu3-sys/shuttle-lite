## 修正した問題

| 問題 | 影響と修正 |
| --- | --- |
| 配置先の手動変更が一覧のグループに反映されない | 表示と実際の承認先が不一致になる。編集後の配置先でグループを再構成し、編集時に選択を解除する。 |
| サーバー更新後も古い選択が残る | 文書バージョン・AI提案などが変わっても一括承認できた。選択時の文書状態を記録し、不一致なら再選択を求める。 |
| 「送信済み」が端末内だけで固定される | 拒否後に修正できず、再読み込みでは処理待ちのロックが消える。ファイル単位の最新コマンドを読み、待機中はロック、拒否後は理由を表示して解除する。ページを定期更新し、コマンド状態だけの変化では編集中のメタデータを破棄しない。 |
| 別ジョブのファイルへのコマンドを受け付ける | 既存Workerに所属確認がなく、他ジョブのファイルの承認・除外・レビュー戻しが成功した。再試行を含む個別操作で、状態更新前に所属を検証する。 |
| 未開始ジョブが開始済みジョブを妨げる | 既存スケジューラーが未開始のQUEUEDジョブを繰り返し選び、後続の移行が進まない。START_JOB処理後のジョブだけを実行対象にする。 |
